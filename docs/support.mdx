## Channels

| Concern | Channel |
|---------|---------|
| General support, account or billing issues | [hello@sibt.ai](mailto:hello@sibt.ai) |
| Enterprise, sales, custom quotas | [hello@sibt.ai](mailto:hello@sibt.ai) |
| Bug reports & feature requests | [GitHub issues](https://github.com/koala73/worldmonitor/issues) (public, open source) |
| Service status & incidents | `GET /api/health?compact=1` — public health probe, no key required |
| Security vulnerabilities | See [security.txt](https://worldmonitor.sibt.ai/.well-known/security.txt) |

The in-app contact form on [/pro](https://worldmonitor.sibt.ai/pro) (`POST /api/leads/v1/submit-contact`) is Turnstile-protected and intended for humans in a browser; agents should use email instead.

## Response expectations

- **Free / Pro / API** — best-effort support via email and GitHub. No formal SLA.
- **Pro Business** — priority support on the same channels. No formal SLA.
- **Enterprise** — dedicated support with committed response times, agreed per contract.

When writing about an API issue, include your key prefix (never the full key), the endpoint, and any request IDs or `X-RateLimit-*` header values you received.

## Before you write in

- **Is it an outage?** Check the public health probe `GET /api/health?compact=1`.
- **Find, create, or replace a `wm_` key** — follow [Find or replace your license / API key](/api-keys). Full keys are shown only once and cannot be recovered; revoke a lost key and create a replacement.
- **Key rotation / limit increases** — [Authentication & Usage](/usage-auth), [Rate Limits](/usage-rate-limits), or email support.
- **Billing self-serve** — invoices, cancel, and renew live in the customer portal at [worldmonitor.sibt.ai/pro](https://worldmonitor.sibt.ai/pro).
